# NEW BULLETPROOF WORKFLOW - Documentation

## Overview

This improved workflow solves the **cognitive overload** and **factual accuracy** problems by:
1. Extracting ground truth FIRST
2. Writing in small, focused phases
3. Validating against extracted facts
4. Using rag-transformers environment for RAG

## Workflow Phases

### Phase 1: EXTRACT (Automated)
**Script**: `notebook_analyzer.py`  
**Environment**: rag-transformers  
**Output**: `{notebook_name}_ground_truth.json`

Extracts from notebook:
- Numerical results (accuracy, F1, precision, etc.)
- Methods used (techniques, optimizers, etc.)
- Figure/table references
- Notebook summary

**Example**:
```bash
conda run -n rag-transformers python agent_quarto_reports/notebook_analyzer.py
```

### Phase 2: STRUCTURE
**Task**: Write Methods + Objectives  
**Input**: Ground truth JSON (methods section)  
**Length**: 300 words Methods + 150 words Objectives  
**Focus**: What was DONE (not results)

**Prompt includes**:
- Methods extracted from notebook
- Techniques used
- No results yet

### Phase 3: VISUALIZE
**Task**: Add ALL figures and tables  
**Input**: List of figures/tables from config  
**Output**: Results section with placeholders  
**Focus**: Structure only, no analysis

### Phase 4: ANALYZE (One at a time!)
**Task**: Write analysis for ONE output  
**Input**: 
- Current figure/table
- Relevant numerical facts from ground truth
**Length**: 200 words per output  
**Focus**: Describe what you SEE

**Key**: Repeat this phase for EACH figure/table separately to avoid cognitive overload

### Phase 5: SYNTHESIZE
**Task**: Discussion + Conclusion  
**Input**: Completed Results section  
**Length**: 300 words Discussion + 150 words Conclusion  
**Focus**: Interpret (no new data)

### Phase 6: FRAME
**Task**: Write Introduction (LAST!)  
**Input**: Complete document  
**Length**: 300 words  
**Focus**: Frame what's ACTUALLY in the document

### Phase 7: VALIDATE (Automated)
**Script**: `content_validator.py` (to be created)  
**Task**: Check all numbers against ground truth  
**Output**: Validation report

## Usage

### Method 1: Use project_agent_config.py (Recommended)

Update your project config:

```python
# assets/<project_name>/project_agent_config.py

from pathlib import Path
from agent_quarto_reports.improved_converter import ImprovedQuartoConverter, Phase

# Paths
NOTEBOOK = Path('assets/student_dropout/figures/student_dropout_nn_151025.ipynb')
OUTPUT_QMD = Path('projects/student-dropout-prediction_nn_201025.qmd')
ENABLE_RAG = True

# Selected outputs
TABLES = ['comparison_neural_networks_all_stages.csv']
FIGURES = [
    ['learning_curve_nn_s3.png', 'val_accuracy_curve_s3_nn.png'],
    ['confusion_matrix_final_model.png']
]

# Create converter
converter = ImprovedQuartoConverter(
    notebook_path=NOTEBOOK,
    output_path=OUTPUT_QMD,
    selected_outputs={'tables': TABLES, 'figures': FIGURES},
    enable_rag=ENABLE_RAG
)

# Run Phase 1: Extract
converter.run_phase_1_extract()

# Generate prompts for phases 2-7
for phase in [Phase.STRUCTURE, Phase.VISUALIZE, Phase.SYNTHESIZE, 
              Phase.FRAME, Phase.VALIDATE]:
    converter.save_phase_prompt(phase)

# Phase 4 (ANALYZE) - Do for each output separately
for idx, table in enumerate(TABLES):
    converter.save_phase_prompt(
        Phase.ANALYZE,
        context={
            'current_result_index': idx,
            'total_results': len(TABLES) + len(FIGURES),
            'current_output': {'type': 'table', 'file': table}
        }
    )

for idx, figure_group in enumerate(FIGURES, start=len(TABLES)):
    converter.save_phase_prompt(
        Phase.ANALYZE,
        context={
            'current_result_index': idx,
            'total_results': len(TABLES) + len(FIGURES),
            'current_output': {'type': 'figure', 'files': figure_group}
        }
    )
```

Then run:
```bash
conda activate rag-transformers
python assets/<project_name>/project_agent_config.py
```

## Key Improvements Over Old System

| Issue | Old System | New System |
|-------|-----------|------------|
| **Cognitive Overload** | Write entire Results at once | One output at a time (200 words) |
| **Factual Accuracy** | No ground truth, agent fabricates | Ground truth extracted, included in prompts |
| **Order** | Intro first (before knowing results) | Intro last (matches actual content) |
| **Validation** | None | Automated validation against ground truth |
| **RAG Environment** | Inconsistent | Always rag-transformers |
| **Database Naming** | Manual, error-prone | Auto-detected from notebook path |

## Validation Checklist

After completing all phases, check:

- [ ] All numbers in document exist in ground_truth.json
- [ ] No accuracy values like 94% that don't appear in notebook
- [ ] No claims about "5 hidden layers" without evidence
- [ ] Methods describe what notebook actually did
- [ ] Results analyze visible figures/tables
- [ ] Discussion interprets actual results
- [ ] Introduction matches actual document content
- [ ] All techniques cited with RAG
- [ ] All citations in references.bib

## Troubleshooting

**Ground truth has 0 figures**:
- Notebook may save figures to disk without displaying
- Check if figures exist in assets/<project>/figures/
- Manually add to `selected_outputs` in config

**Numbers don't match**:
- Check ground_truth.json for what was actually extracted
- Notebook might have multiple runs with different results
- Use most recent/relevant numbers

**RAG not working**:
- Verify: `conda activate rag-transformers`
- Check: BM25 file exists: `assets/<project>/references/.chroma/{project}_references_bm25.pkl`
- Rebuild: `converter.rag_system.index_references(force_reindex=True)`
